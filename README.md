# 🛒 Forever – Full Stack MERN E-Commerce Application

Forever is a **modern, full-stack e-commerce web application** built using the **MERN stack**.  
It provides a smooth shopping experience with secure authentication, product management, cart functionality, and online payments.

This project demonstrates **real-world full-stack development practices**, including frontend UI, backend APIs, database design, authentication, and deployment.

---

## 🚀 Live Project

Frontend: https://forward-frontend-tau.vercel.app  
Backend: https://forward-backend.vercel.app  

---

## 🧰 Tech Stack

### Frontend
- React.js
- Redux
- JavaScript (ES6+)
- HTML5
- CSS3
- Tailwind CSS

### Backend
- Node.js
- Express.js
- REST APIs

### Database
- MongoDB (Mongoose)

### Payments
- Stripe Payment Gateway

### Deployment
- Vercel (Frontend & Backend)

---

## ✨ Features

### 👤 User Features
- User signup & login
- JWT-based authentication
- Browse products by category
- Add products to cart
- Update cart quantity
- Secure checkout with Stripe
- Order placement

### 🛠️ Admin Features
- Admin authentication
- Add new products
- Update existing products
- Delete products
- Manage orders
- Product image handling

---

## 🔐 Security
- JWT authentication
- Protected API routes
- Secure environment variables
- Role-based access (User / Admin)

## ⚙️ Installation & Setup

### 1️⃣ Clone the repository
```bash
git clone https://github.com/yourusername/forever-ecommerce.git
cd forever-ecommerce
cd frontend
npm install
npm run dev
```

Backend
```bash
cd backend
npm install
npm start
PORT=5000
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret
STRIPE_SECRET_KEY=your_stripe_secret_key
```
